Where to go deeper

The path after these labs

These are topics for further study. Each question builds on an experiment above.

  1. How much do two features tell you twice? Extend projection into covariance, correlation, rank, matrix factorization, eigenvectors, and SVD. Reconstruct a dataset with progressively fewer components.
  2. Which story could have generated these data? Start from base rates and sampling. Explore joint and conditional distributions, expectation, likelihood, maximum likelihood, priors, and posterior prediction.
  3. Is an apparent improvement repeatable? Build from confidence intervals into bootstrap estimates, hypothesis tests, power, multiple comparisons, and randomized experiments. For sequential data, account for autocorrelation and evaluate forward in time.
  4. What happens when a model gets thousands of weights? Extend the loss bowl to multiple regression, regularization, partial derivatives, Jacobians, Hessians, mini-batches, momentum, and adaptive optimizers.
  5. How do these parts become modern AI? Combine attention with embeddings, residual connections, and normalization. Follow probability into generative models and sampling, or explore expected return and Bellman updates for reinforcement learning.
